# 視覚効果と負荷

設定の「視覚効果」で切り替えられます。

- **自動**: Three.js の粒子・光跡と、カードの厚み・反射・展開を組み合わせます。
  WebGL 2 が利用できない場合や、描画負荷が継続して高い場合は軽量表示へ切り替えます。
- **軽量**: Three.js を読み込まず、CSS / SVG の演出を使います。
- **オフ**: 装飾のアニメーションを止めます。コピー・検索・ファイル参照などの操作は共通です。

OS の「動きを減らす」設定を優先し、その場合も GPU の演出を読み込みません。
文字と操作ボタンは HTML のままで、クリップボード本文やファイル内容を GPU に渡しません。

## 描画の予算

- 粒子128個・短い光跡32本まで。1フレームあたり最大2回の描画。
- 描画用の画像テクスチャ、シャドウマップ、ブルーム用の画面全体の中間バッファは使いません。
  粒子の発光は小さなシェーダーで描きます。
- キャンバスは約72万画素まで、ピクセル比は1.25までに制限します。
- 描画は操作中の約0.3〜0.62秒だけ、毎秒約30フレームを上限にします。
  動きが終わると `requestAnimationFrame` の予約も止めます。
- 非表示・フォーカス喪失時はすぐ停止し、5秒続くと GPU リソースを解放します。
- WebGL のコンテキスト喪失時も軽量表示へ切り替えます。

Three.js は別チャンクとして遅延読み込みします。現時点の追加チャンクは gzip 約132 KBです。
外部の CDN、画像、3Dモデルへの通信は行いません。
負荷・滑らかさは OS、WebView、GPU とドライバーによって変わるため、
「軽量」を明示的に選べるようにしています。

## 検証

`tests/ui/effects.spec.ts` で次を確認します。

- 軽量モード・動きを減らす設定では Three.js のモジュールを読み込まないこと。
- WebGL がなくても従来のカード操作とコピーが動くこと。
- シェーダーが動き、描画回数・画素数・テクスチャ数・ジオメトリー数が予算内であること。
- 操作終了後はフレーム予約が増えず、非表示後にキャンバスを解放すること。

シェーダーのテストでは隔離したブラウザーのソフトウェア GPU を明示的に許可します。
通常の自動モードでは `failIfMajorPerformanceCaveat` を要求し、軽量表示を選べるようにします。
