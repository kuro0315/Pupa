# ファイルのコピー履歴

現在は **Linux のローカルファイル・フォルダー** に対応します。
Windows / macOS のファイルコピーは未対応です。テキストは従来どおり使えます。

1. ファイルマネージャーでファイルやフォルダーを選び、コピーします。
2. Pupa を開くと、ファイル名と件数を表示したカードが現れます。
3. カードをクリックして再コピーし、貼り付け先のファイルマネージャーで貼り付けます。

検索の「ファイル」で絞り込めます。複数選択は一つのカードになり、最大100個まで扱います。
ファイル名に空白や日本語を含んでいても扱えます。

履歴は **元ファイルへの参照** です。ファイル本体を Pupa に保管・バックアップしません。
元ファイルを削除・移動したり、そのドライブを外したりすると再コピーできません。
再コピー時に元ファイルが存在しない場合はエラーを表示し、カードを閉じません。
内容を変更したファイルは、再コピーした時点の内容が対象になります。

Pupa はファイルの複製・移動・削除や自動貼り付けを行いません。
切り取り操作を検出した場合も、Pupa からの再利用は **コピー** として扱います。
ネットワーク URI、画像そのもの、ファイルの内容プレビューには対応しません。
一時停止・収集開始時の基準リセット・履歴件数・ピン留めは、テキストと共通です。
Pupa を終了すると、保持中のファイルクリップボードが使えなくなる場合があります。

通常はメモリだけに保持します。履歴保存を有効にするとファイル名と絶対パスも
端末に平文で保存します。履歴カードの削除で元ファイルが消えることはありません。

Wayland のバックグラウンド取得可否は、ファイルマネージャーとコンポジターの
クリップボード共有に依存します。XWayland が無効な環境や権限付き・サンドボックス内の
ファイルは取得・貼り付けできない場合があります。
