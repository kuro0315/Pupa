# Pupa をインストールする

## はじめに

Pupa 0.2 は Tauri + Rust で動きます。Electron / Chromium を同梱せず、OS の WebView を使用します。

Pupa の CI 成果物は **未署名・未公証の開発ビルド**です。OS によって起動が拒否されることがあります。OS の安全機能を無効にしたり、警告を迂回したりしないでください。通常のユーザー向け配布には、署名・公証が完了した正式版を使用してください。

Actions が成功しても、そのことだけで実機動作や安全な一般配布が保証されるわけではありません。各 OS のネイティブ操作は [配布チェックリスト](DISTRIBUTION.md) の項目を別途確認します。

## ファイルの入手

1. [Build desktop apps](https://github.com/kuro0315/Pupa/actions/workflows/desktop-build.yml) を開きます。
2. 意図したコミットの実行を選び、対象 OS のジョブが成功していることを確認します。
3. Artifacts から `Pupa-windows-x64-<実行番号>`、`Pupa-macos-arm64-<実行番号>` / `Pupa-macos-x64-<実行番号>`、または `Pupa-linux-x64-<実行番号>` を選びます。
4. ダウンロードした ZIP を展開します。
5. 自分の CPU と OS に合うインストーラーを選びます。

GitHub にサインインしており、リポジトリの読み取り権限が必要です。Artifacts は 14 日で期限切れになります。成果物がない場合は、権限のある管理者が Actions の「Run workflow」を実行し、成功後の成果物を確認してください。CI から GitHub Releases への自動公開は行いません。

参考: [GitHub 公式の Artifacts ダウンロード手順](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/download-workflow-artifacts)

## Windows x64

対象は Windows 10 / 11 の x64 版です。表示には Microsoft WebView2 が必要です。未導入の場合はインストーラーが公式ランタイムを取得するため、ネット接続が必要になることがあります。ARM64 / 32-bit 向けのネイティブ配布物は現在用意していません。

1. `Pupa-<version>-windows-x64-setup.exe` を選びます。
2. 署名済みで信頼できる配布元の版であることを確認してから、インストーラーの案内に従います。
3. インストール先を確認し、スタートメニューの「Pupa」から起動します。デスクトップショートカットは標準では作成しません。
4. `Ctrl Shift Space` でカードが開くことを確認します。

未署名の開発版で SmartScreen やセキュリティ製品が止めた場合は、そのまま実行せず、署名済み版の提供を待つか、ソースを確認できる開発者が開発環境で検証してください。

削除は Windows の「設定 → アプリ → インストールされているアプリ」から Pupa をアンインストールします。履歴や設定は自動で完全削除する構成ではないため、先にアプリで履歴削除と永続保存の無効化を行ってください。詳しくは [データの保存先](PRIVACY.md#保存先と削除) を確認してください。

## macOS

macOS 13 以降が対象です。OS 内蔵の WKWebView を使用します。

Apple Silicon（M シリーズ）は `arm64`、Intel Mac は `x64` を選びます。1 つの Universal アプリではなく、CPU ごとに別のファイルです。

1. `Pupa-<version>-mac-arm64.dmg` または `Pupa-<version>-mac-x64.dmg` を選びます。
2. 署名・公証済みの信頼できる版であることを確認してから DMG を開きます。
3. Pupa を Applications フォルダーにドラッグします。
4. DMG を取り出し、Applications から Pupa を起動します。
5. `⌘ ⇧ Space` でカードが開くことを確認します。

現在の CI は Apple Developer ID による署名も公証も行わないため、Gatekeeper に拒否される可能性があります。隔離属性の削除や Gatekeeper の無効化などの迂回操作は案内しません。正式配布前の署名・公証を実施してください。

Pupa は自動貼り付けをしないため、アクセシビリティ権限を求めません。既定のショートカットが他のアプリと競合する場合は Pupa の設定で変更できます。

削除する場合はトレイ / メニューバーから Pupa を終了し、Applications の Pupa をゴミ箱へ移動します。設定や任意保存した履歴は別に残る場合があります。

## Linux x64

CI の Linux ビルド環境は Ubuntu 24.04 x64 です。それより古い glibc のディストリビューションでの互換性は保証しません。deb は WebKitGTK 4.1 などのシステム依存ライブラリーを使用し、パッケージマネージャーが必要に応じて取得します。

X11 セッションを推奨します。Wayland ではバックグラウンドのクリップボード取得、ショートカット、ウィンドウ位置の扱いがデスクトップ環境によって異なります。Wayland でグローバルキーが動かない場合は、トレイから開くか X11 セッションで使用してください。

### AppImage

1. `Pupa-<version>-linux-x86_64.AppImage` を任意のフォルダーに置きます。
2. ファイルのプロパティから「プログラムとして実行」を許可します。
3. ダブルクリックして起動します。

ターミナルで実行権限を付ける場合は、ダウンロードしたファイル名に置き換えて実行します。

```sh
chmod +x Pupa-<version>-linux-x86_64.AppImage
./Pupa-<version>-linux-x86_64.AppImage
```

AppImage の起動に必要な FUSE がない環境では、ディストリビューションの公式手順で必要なパッケージを確認するか、対応する Debian 系環境では deb 版を使ってください。WebView のサンドボックスを無効化して常用しないでください。

### Debian / Ubuntu 系の deb

`Pupa-<version>-linux-amd64.deb` のあるフォルダーで、以下を実行します。システムにパッケージをインストールするため、管理者権限が必要です。

```sh
sudo apt install ./Pupa-<version>-linux-amd64.deb
```

インストール後はアプリケーション一覧の Pupa から起動します。deb のインストール自体はパッケージマネージャーが必要な依存関係をダウンロードする場合がありますが、Pupa 本体は通信しません。

トレイが見えなくても、ランチャーから Pupa を再度起動してカードに戻れます。グローバルキーが動作しない場合は、他のアプリとの競合、ポータルの対応、X11 セッションでの動作を確認してください。

## ハッシュの照合

`SHA256SUMS.txt` は同じビルドのインストーラーの SHA-256 を記録しています。破損・取り違えの確認に使えますが、ファイルとハッシュが同じ配布元にあるため、**署名や配布元の信頼性確認の代わりにはなりません。**

Windows PowerShell:

```powershell
Get-FileHash .\Pupa-<version>-windows-x64-setup.exe -Algorithm SHA256
```

macOS:

```sh
shasum -a 256 Pupa-<version>-mac-arm64.dmg
```

Linux:

```sh
sha256sum -c SHA256SUMS.txt
```

## Electron 0.1 版を使っていた場合

旧版を終了してから Tauri 0.2 版を起動してください。履歴と設定の保存先は異なり、旧データを自動取得・削除しません。新しい保存先は [プライバシーガイド](PRIVACY.md#保存先と削除) に記載しています。

## 最初のコピーが出ない・カードが出ないとき

- 起動時にすでにコピーされている内容は、秘密の意図しない取り込みを減らすためスキップします。起動後に別の文章をコピーして約 1 秒待ってください。
- 一時停止・画面ロック・サスペンドから戻った直後も、現在のクリップボードは取り込みません。
- テキストのみが対象です。画像やファイルのコピーは履歴に出ません。
- 登録済みのキーが他のアプリに使われている場合、OS は登録を拒否することがあります。トレイから Pupa を開き、別のキーに変更してください。
- Wayland では機能制限があり得ます。ポータルやデスクトップの対応状況を確認するか、X11 セッションを使用してください。
- 開いているウィンドウを閉じても、バックグラウンドの記録は続きます。止めたい場合は記録を一時停止するか、トレイから終了してください。
