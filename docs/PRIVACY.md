# プライバシーとセキュリティ

Pupa はクリップボードのテキストを扱うアプリです。コピー内容には秘密が混ざる可能性があるため、「ローカルだけなら無条件に安全」とは考えていません。

## 初期状態

- 履歴はメモリだけに保管し、履歴ファイルは作りません。
- 設定は端末内に保存します。
- 起動時点のクリップボードは初期値として扱い、履歴に取り込みません。
- 記録の一時停止中はクリップボードを読みません。再開時も現在の値を飛ばし、次の変更から取得します。
- 画面ロック・サスペンド中の記録を止め、復帰時に現在の内容を取り込みません。OS が対応するイベントを通知することが前提です。画面ロックの検出は OS の対応と状態取得に依存します。Linux ではロック前に手動で記録を一時停止してください。

## 記録する内容

約 700 ms ごとに OS のプレーンテキストクリップボードを確認します。画像、ファイルの中身、リッチテキストの書式は保管しません。テキストと一緒に、履歴表示用の作成時刻やピン状態などを保持します。

URL やコードの分類は端末内のテキスト処理です。内容を外部 AI や Web サービスに送信しません。URL 先へのアクセス、リンクプレビューの取得、コードの実行は行いません。

コピー操作を完全に記録するアプリではありません。ポーリング間隔の間に値が変わると途中の内容を取得できません。また、同じ値の繰り返しコピーや OS・アプリ独自の形式を、別のコピーとして認識できない場合があります。

## アプリ情報（推定）

初期設定では、クリップボードの変更を検出した際に最前面だったアプリの名前と、取得できたローカルのアイコンを履歴に添えます。**実際にコピーしたアプリを保証しません。** コピー直後に別アプリへ移動した場合や、別プロセスからのコピーでは一致しないことがあります。カードに「推定」と表示し、取得できない場合は「アプリ不明」とします。

- macOS: NSWorkspace の前面アプリ情報。Windows: 前面ウィンドウのプロセス名とローカルアイコン。Linux X11: WM_CLASS の名前のみ。Wayland は非対応です。
- ウィンドウタイトル、ブラウザーの現在 URL、プロセスのコマンドラインは記録しません。コピー本文に含まれる URL は本文の一部です。
- ネットワークからアイコンを取りません。アクセシビリティ権限を自動要求しません。制限・タイムアウト時は不明のままにします。
- 設定の「収集時のアプリを記録（推定）」を無効にすると、以後の取得を止めます。既存の名前・アイコンは履歴に残るため、消すには該当履歴を削除してください。
- 永続保存を有効にすると名前・アイコンも履歴と共に保存します。これらも履歴全体の容量制限に含みます。

## 履歴の上限

- 標準 60 件、設定で 30 / 60 / 100 件。現在の件数より上限を減らす場合、ピンを含めた削除の明示確認が必要です。
- 1 件あたり UTF-8 64 KiB、名前・アイコンを含む履歴全体で 2 MiB。
- 1 件の上限を超えるテキストは保存しません。
- 上限を超えると、古い非ピン項目から整理します。全件がピンの場合は古いピンも対象になります。
- ピン留めは無制限・永久保存を意味しません。全履歴削除はピンも削除します。

## 秘密をコピーする前に

**パスワード、秘密鍵、API キー、認証コード、決済情報、仕事上の機密情報を扱う前に、記録を一時停止してください。**

macOS では、他のアプリが付ける concealed / transient のクリップボードマーカーを可能な範囲で尊重します。しかし、すべてのパスワードマネージャーがマーカーを付けるわけではなく、他の OS で同じ仕組みが使えるとは限りません。文字列から秘密を確実に判定することはできません。自動除外を安全対策の代わりにしないでください。

一度履歴へ取得した後で元のアプリがクリップボードを消しても、Pupa の既存履歴まで自動削除されるとは限りません。不要な項目は個別削除または全履歴削除をしてください。

## 任意のローカル保存

設定で永続保存を有効にすると、履歴を端末内の `history.json` に保存します。**暗号化しません。** ピン留めを含む本文がプレーンテキストで記録されます。

同一ユーザーとして動く別のアプリ、管理者、バックアップソフトなどから読まれる可能性があります。ディスク暗号化が有効でも、ログイン中の同一ユーザーからの読み取りを防ぐものではありません。

保存を無効にすると、Pupa は履歴ファイルを削除します。現在のセッションの履歴はメモリ上に残るので、必要なら全履歴削除も行ってください。ファイル削除はディスクの安全な消去ではなく、OS のバックアップ・スナップショット・同期ソフトが持つコピーまでは削除しません。

## 保存先と削除

Tauri の `app_data_dir` 配下に `settings.json` と、保存を有効にした場合だけ `history.json` を置きます。書き込みの途中では `.tmp` ファイルを使用します。

通常の場所は以下です。OS の環境変数・設定・アプリの実行名によって異なる場合があります。

| OS | 通常の保存先 |
| --- | --- |
| Windows | `%APPDATA%/jp.kuro0315.pupa/` |
| macOS | `~/Library/Application Support/jp.kuro0315.pupa/` |
| Linux | `$XDG_DATA_HOME/jp.kuro0315.pupa/`、未設定時は `~/.local/share/jp.kuro0315.pupa/` |

履歴を消すとき:

1. アプリで全履歴削除を実行します。ピンも削除します。
2. 永続保存が有効なら、設定で無効にします。
3. 完全に設定もリセットしたい場合は、Pupa を終了してから上記の保存先を確認し、自分で Pupa のデータフォルダーを削除します。

アンインストールはユーザーデータの完全削除を保証しません。Pupa の履歴削除は OS のクリップボード自体も消す操作とは別です。OS のクリップボード履歴・他のクリップボードアプリ・バックアップは、それぞれ別に管理してください。

## ネットワークと権限

- テレメトリー、解析、広告、クラウド同期、自動更新のネットワーク処理はありません。
- 権限を使って元のアプリにキー入力したり、自動で貼り付けたりしません。
- 通常の使用で macOS のアクセシビリティ権限は不要です。
- Linux Wayland ではグローバルショートカットや監視、配置に制限があります。動作しない場合は X11 を使用してください。
- ビルド時の npm・Cargo・Tauri のダウンロード、およびインストール時の OS WebView / 依存ライブラリーの取得は、完成アプリの通常動作とは別です。

## アプリの保護

Rust が OS 機能と履歴を管理し、レンダラーは検証された限定コマンドだけで操作します。任意ファイル・シェル・HTTP・クリップボードの JavaScript 権限は付与しません。コピー内容を HTML として実行せず、テキストとして表示します。アプリのウィンドウから意図しない外部ページを開かせません。

ただし、Tauri・OS の WebView と OS、実行端末が侵害されていないことまでは保証できません。機密情報を扱う場合は永続保存を無効のままにし、記録を止める運用を優先してください。

## 不具合の報告

公開 Issue には実際のクリップボード本文、履歴ファイル、設定ディレクトリ、秘密を含むスクリーンショットを貼らないでください。再現手順には架空のテキストを使い、OS、CPU、Pupa のバージョン、Wayland / X11 の別だけを添えてください。安全上の問題は、公開せずリポジトリ管理者の非公開の報告窓口が用意されている場合にその窓口を使用してください。
